

# Facebook Metrics SQL Analysis

A MySQL data analysis project using Facebook metrics from a cosmetic brand to explore post performance, engagement, and posting trends.

## Dataset

* 500 Facebook post records
* Includes post type, category, month, reach, impressions, likes, comments, shares, and total interactions
* Paid and unpaid post information

## SQL Concepts Practiced

* `SELECT`, `WHERE`, `DISTINCT`
* `COUNT`, `SUM`, `AVG`, `MIN`, `MAX`
* `GROUP BY`, `HAVING`
* `ORDER BY`, `LIMIT`
* `CASE` statements
* Subqueries
* window functions

## Analysis

The project analyses:

* Post performance by type
* Paid vs. unpaid posts
* Monthly posting trends
* Likes, shares, comments, and interactions
* Top-performing posts

# Key Insights

• Identified the post type with the highest average engagement.
• Compared paid and unpaid posts based on likes, shares, and interactions.
• Identified the month with the highest posting frequency.
• Analyzed the relationship between post reach and engagement.
• Identified the highest-performing posts based on total interactions.
